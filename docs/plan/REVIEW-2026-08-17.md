## 3. 仍需注意的风险

1. **行号漂移**：plan 中的行号是评审时快照；执行时必须先用 `rg -n '<符号>' src` 重新定位。
2. **分支状态**：当前在 `token-optimization` 分支；方案合入/执行前应确认目标分支，尤其 Phase 1 的 `platforms→web` 解耦会与近期 token 优化改动有文件重叠。
3. **性能方案优先级**：建议先完成对应模块的结构性拆分，再执行该模块性能项；不要同文件同 PR 混改。
4. **死代码清理**：`RUSTFLAGS=--force-warn=dead_code` 的结果会随分支变化；每个 DC PR 前必须重新生成报告。
5. **图片降采样**：logo/wallpaper 降采样虽然不改功能，但会改变视觉清晰度；需经维护者确认 2x/3x 目标尺寸。
